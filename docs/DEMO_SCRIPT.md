# Demo script (60–90초)

녹화 대상: https://roomy-page-workbench.hommy.workers.dev/workbench  
자막/보이스오버 한 줄씩. 성공만 찍지 말고 **실패 한 컷**을 넣는다.

## 타임라인

| 초 | 화면 | 말할 것 |
| --- | --- | --- |
| 0–8 | 히어로 + 시나리오 목록 | “내부업무 AX용 릴리즈 워크벤치. AI 생성이 아니라 검토·검증·게이트.” |
| 8–20 | rw-004 선택 → 실행 시작 → 타임라인 | “요구사항을 구조화하고 원문 근거를 붙입니다.” |
| 20–35 | 계획 승인 → diff · preview · QA | “승인 후에야 패치·미리보기·자동 QA가 돕니다.” |
| 35–48 | 게이트 승인 | “사람이 최종 릴리즈를 결정합니다.” |
| 48–70 | rw-012 또는 rw-005 | “근거 없으면 승인 불가 / 스트리밍 중 취소도 상태가 남습니다.” |
| 70–85 | /evals | “합성 32과제. 표본·모델·프롬프트 버전을 같이 공개합니다.” |
| 85–90 | 로고/URL | URL 한 번 더. |
